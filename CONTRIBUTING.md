# Contributing

This guide is only useful if it stays correct as attacks change. Help is very welcome.

- **A sign the guide misses, or a new attack wave?** Use the
  [new attack sign form](https://github.com/Echolonius/was-my-github-hacked/issues/new?template=new-sign.yml)
  and link a public write-up.
- **Something wrong or out of date?** Use the
  [correction form](https://github.com/Echolonius/was-my-github-hacked/issues/new?template=correction.yml), with a
  link to GitHub's docs or another source.
- **Pull requests:** keep the language plain, keep each step something a beginner can follow, and give a source for
  every claim. AI-assisted pull requests are welcome; say so in the description.

**Never post your own security log, tokens, keys or private repo names in an issue.** If your account is hacked
right now, follow the guide and contact [GitHub Support](https://support.github.com/contact). This repo can't see
or fix anyone's account.
