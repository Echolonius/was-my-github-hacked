# Security

**If your own GitHub account is hacked right now,** follow [the guide](README.md) and contact
[GitHub Support](https://support.github.com/contact). Please don't open an issue here with details of your account.

**If something in this guide could cause harm** (a wrong step, a link that went bad, advice an attacker could abuse),
report it privately: [report a problem](https://github.com/Echolonius/was-my-github-hacked/security/advisories/new).
